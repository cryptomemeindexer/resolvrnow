# ResolvrNow brand

The mark is the **Resolve knot**: a tangled loop that straightens into a check mark, so the icon
reads as a problem being resolved. At large sizes the loop also reads as the bowl of a handwritten
"R".

| File | Use |
|---|---|
| `resolvrnow-mark.svg` | App icon on its coral tile: favicons, avatars, social profiles |
| `resolvrnow-mark-1024.png`, `-512.png`, `-256.png` | The app icon as PNG, with transparent corners |
| `resolvrnow-app-icon-180.png` | Full-bleed square for iOS home screens (iOS rounds the corners) |
| `resolvrnow-knot.svg` | The knot alone in coral, for light backgrounds |
| `resolvrnow-knot-white.svg` | The knot alone in white, for coral or dark backgrounds |
| `resolvrnow-logo-on-light.png` | Mark and wordmark for light backgrounds |
| `resolvrnow-logo-on-dark.png` | Mark and wordmark for dark backgrounds |

## Colors

| Name | Value | Used for |
|---|---|---|
| Mark gradient | `#ff8a68` to `#f25d3f` to `#dc4329` | The app icon tile only |
| Coral 500 | `#ee5738` | Large titles, numbers, active states |
| Coral 600 | `#d3412a` | Buttons and links (meets WCAG AA on white) |
| Ink | `#211c15` | Text |
| Muted | `#5c5248` | Secondary text |
| Line | `#e8e0d6` | Borders |
| Gold | `#b08d52` | The thin accent line at the top of pages |

## Type

The wordmark is Helvetica Neue Bold with -2% tracking. The web app falls back to Inter where
Helvetica isn't installed.

## Usage

- Keep clear space of at least a quarter of the mark's width on every side.
- Don't use the tile below 16 px.
- Don't recolor, rotate, stretch or outline the knot, and don't place the coral tile on a coral
  background.
