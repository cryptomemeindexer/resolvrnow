03 / APISame paths · same queries · same responses

Speaks the API your tools already know.

Point existing integrations, scripts and migration tools at ResolvrNow. The paths, encoded queries and response formats match what they expect.

  • /api/now/table/{table}Table
  • /api/now/stats/{table}Aggregate
  • /api/now/attachmentAttachments
  • /api/now/import/{staging_table}Import sets
  • /api/now/batchBatch
  • /api/now/cmdb/instance/{class}CMDB

Encoded queries with dot-walking, display values, pagination headers, Basic auth, API tokens and browser sessions.

# Open critical incidents, with display values
curl -u alex.rivera:demo1234 \
  "http://localhost:8080/api/now/table/incident\
?sysparm_query=active=true^priority=1\
&sysparm_fields=number,short_description,priority,state,assigned_to\
&sysparm_display_value=true&sysparm_exclude_reference_link=true\
&sysparm_limit=1"

# 200 OK · X-Total-Count: 1
{
  "result": [{
    "number": "INC0010075",
    "short_description": "Email delivery delayed for all Northwind mailboxes",
    "priority": "1 - Critical",
    "state": "In Progress",
    "assigned_to": "Priya Nair"
  }]
}
