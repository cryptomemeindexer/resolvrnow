Drop-in compatible

Speaks the API your scripts already use.

ResolvrNow implements the widely used Table, Aggregate, Attachment, Import Set, Batch, CMDB, Catalog, Change and Knowledge REST APIs. It supports encoded queries (with dot-walking, OR clauses and date macros), display values and pagination headers, so existing integrations and migration scripts keep working.

  • sysparm_query, sysparm_fields, sysparm_display_value and friends
  • Basic auth, API tokens and session cookies
  • Built-in importer to copy records from another compatible instance
# Same request, same response shape
curl -u agent:•••• \
  "https://itsm.example.com/api/now/table/incident?\
sysparm_query=active=true^priority=1^ORDERBYDESCsys_created_on&\
sysparm_fields=number,short_description,assigned_to&\
sysparm_display_value=true&sysparm_limit=5"

AI that works offline, and better online

Predict, summarize, resolve.

Built-in machine learning classifies and routes tickets, finds similar incidents and suggests knowledge, all locally with no external service. Add a Claude API key to get incident summaries, resolution notes, knowledge drafts and grounded answers. An MCP server lets your AI agents work tickets safely, with the same access controls as your people.

Self-host in minutes

Your data, your infrastructure.

A single Node.js process with an embedded SQLite database. It runs on a laptop, a small VM or any container platform. Demo data for a fictional company is one flag away.

  • One container, one volume, no external dependencies
  • Agent workspace and employee self-service portal included
  • MIT licensed: fork it, extend it, ship it
# Docker
git clone https://github.com/cryptomemeindexer/resolvrnow
cd resolvrnow && docker compose up -d

# or Node.js 22+
npm ci && npm run build
RESOLVRNOW_DEMO=true npm start
# → http://localhost:8080  (demo users: password demo1234)
